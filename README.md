# Frontend

## Installation and Setup

Make sure you have node version 24.1.0
Make sure you have npm installed
* Pull the Repository
* Go to frontend directory
`cd frontend`
* In the terminal type `npm install` to install all the libraries and dependencies
* After all the dependencies are installed, type `npm run dev` to run the server
* Visit http://localhost:5173 to view the website.
